## 好音乐，随手就能听

- **想听什么，搜一下。** 输入歌名或歌手，从 B 站找到喜欢的版本。热门推荐与最近听过，打开就能接着听。
- **好现场，值得好音质。** 聆听原声、翻唱和完整演唱会，按音源与账号权益选择 Hi-Res 等音质。
- **把喜欢，收进自己的歌单。** 一键收藏，拖动歌曲加入歌单；随时添加、排序和整理播放队列。
- **熟悉的 Mac 体验。** 通透的玻璃界面、键盘控制、系统播放封面。退出时记住队列和进度，下次接着听。

## 三步开始

1. **安装。** [下载最新版](https://github.com/kcxain/bMusic/releases/latest)，解压后把 BMusic 拖入「应用程序」。支持 Apple 芯片 Mac，macOS 14 及以上；macOS 26 带来液态玻璃效果。
2. **登录。** 点击左下角头像，使用哔哩哔哩 App 扫码，连接你的账号。
3. **播放。** 搜索歌名或歌手，按回车，点击播放。喜欢就点爱心，想整理就创建歌单。

之后可在 **BMusic → 检查更新…** 获取新版本，也可以在设置中开启自动检查。

## 你的音乐，留在你的 Mac

收藏、歌单和播放记录保存在本机，登录凭据由系统钥匙串保管。音质随歌曲和账号权益提供，收藏与歌单由 BMusic 在本地管理。
