# 本地开发记录

以下记录对应发布前迭代；当前行为以 README 为准。

## 0.2 界面与长音频

主题采用 B 站粉 `#FB7299`，账号头像直接读取 B 站资料。标志源文件为 [`resources/BMusic.svg`](resources/BMusic.svg)，结合小电视天线与音符。macOS 26+ 使用系统 Liquid Glass，旧系统使用原生材质；窗口隐藏标题栏，播放控制使用悬浮玻璃材质。

旧实现将整条 DASH fMP4 交给 AVFoundation，导致启动时在远端文件中反复跳读 fragment、建立索引。现实现直接解析文件开头的 `sidx`，生成按分段索引定位的 HLS 播放列表，播放器只请求当前需要的音频片段。一次三小时 AAC 测试在约 1.95 秒完成元数据准备，约 4.4 秒内完成首次播放与跳转到 60 秒后的续播（含搜索和接口请求）；时间随 CDN 和网络变化。Hi-Res 仍以实际音源和账号权限为准。

```bash
BMUSIC_LIVE_TESTS=1 BMUSIC_TEST_BVID=BV1krsE6WEGn ./scripts/test.sh
```

## 0.3 播放状态与系统集成

- `PlaybackPosition` 统一管理播放时钟、拖动预览、待完成跳转和请求标识。拖动时显示目标位置，松手提交一次跳转；过期回调与播放时钟保持隔离，暂停意图持续有效。
- `PlaybackTimeline` 单独发布进度，10 Hz 刷新只影响进度控件。进度条支持缓冲区、悬停时间、Shift / 垂直拖动精细定位和辅助功能增减操作。
- `NowPlayingPublisher` 独立发布系统媒体元数据与封面。封面最大 600px，缓存预算 8 MiB，切歌取消旧请求；暂停、跳转立即更新，常规时钟最多每 5 秒同步一次。
- 原始音频片段缓存预算 12 MiB，用于回拖重用；网络请求仍按分段索引定位。
- Logo 使用透明背景的小电视轮廓和单音符。`resources/BMusic.svg` 为设计源，打包脚本同步 SwiftPM 资源与 ICNS，应用启动时主动更新 Dock 图标。

本次真实三小时 AAC 测试中，跳至 60 秒、8179 秒、再返回 60 秒，分别约 0.73 / 1.41 / 0.57 秒完成定位并续播，耗时取决于 CDN 和网络。13 项测试覆盖封面保留、过期封面隔离、连续跳转、暂停跳转、拖动时钟隔离，以及实际音频播放与封面下载。

## 0.3.1 主页与搜索

- 主页参考 Apple Music 的封面层级：音乐榜前 12 名采用竖向大卡片，下一行显示最近听过的方形封面；侧栏独立提供搜索、主页、资料库和歌单。
- 推荐来自 B 站音乐区排名接口，按接口顺序展示，缓存 15 分钟；请求失败时显示重试入口。
- 搜索历史保存在本机偏好设置，最多 20 条，去重置顶，支持点击重搜、单条删除和清空；搜索结果页保留历史入口。
- 应用图标改为白色圆角底板与粗壮的 B 站粉双连音符，SVG 与 Dock 图标同步生成。侧栏移除品牌图标和名称，主页移除技术说明与宣传标语。

## 0.3.2 窗口与歌单交互

- 主窗口使用固定的 `main` 标识，处理 macOS reopen 事件；关闭窗口后通过 Dock / Finder 再次打开会恢复主窗口，播放状态由应用模型保留。
- 主页顺序为最近听过、热门推荐。两行共享原生横向滚动组件，悬停时显示两侧半透明分页箭头，按可见卡片数量翻页，保留触控板滚动和卡片对齐。
- 主页封面、歌曲列表和底部播放封面支持拖放到侧栏歌单。自定义 Transferable 数据携带曲目和分 P 信息，目标高亮、成功反馈、原子保存和按曲目标识去重。
- 白底单音符适度加粗，符头略微放大。

## 0.4.0 统一播放入口与布局

- `TrackPlaybackState` 依据 BVID + 分 P 与播放意图生成统一状态、按钮图标和操作文案；`Player.activate` 负责同曲暂停/继续、其他曲目开始播放。主页、推荐、收藏、搜索、分 P 和播放队列共用该入口。
- 播放栏采用左右等宽、中央固定 140pt 的几何布局。中央三个按钮始终居中，左侧歌名单行截断，右侧音量滑杆直接可用。随机/循环保留在菜单中。
- 搜索区移除单独的最大宽度限制，与内容区使用统一左右边距；隐藏标题文字，保留原生统一工具栏。
- 新增跨来源曲目标识、暂停图标、失败重试和分 P 隔离测试。Release 应用版本为 0.4.0。

## 0.4.1 悬浮播放与原生玻璃

- 播放器以底部 overlay 悬浮在详情列，常规高度 86pt；内容滚动区域延伸到窗口底部。根据播放器实测高度为滚动内容末尾留出空间，最后一首和搜索分页可滚到播放器上方。
- 播放、切歌、队列、搜索历史和主要操作采用系统玻璃按钮，搜索框、轮播箭头、封面播放标记与时间提示采用原生 Liquid Glass。macOS 14–25 使用系统材质与按钮兼容样式。
- 搜索范围内嵌搜索框，回车提交，右侧时钟打开历史。音量保留直接拖动的小号系统滑杆。
- 打包时显式记录当前 SDK 版本，让系统启用对应的窗口与控件外观。
- 白底粉色单音符扩大左下符头，右上旗部加大并延长，SVG、应用与 Dock 图标共用同一资源。
- 玻璃透明度交给系统材质管理；主页标题上移 10pt，保留统一的内容左边距。
